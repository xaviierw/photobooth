Web Photobooth

A simple browser-based photobooth that lets you capture photos using your webcam and generate a three-frame photostrip instantly. No installation needed — everything runs on the client side.

Features

- Live webcam preview and mirrored capture
- Capture up to 3 photos per session
- Automatic three-frame photostrip layout
- Selectable frame templates
- High-resolution PNG download
- Quick reset with one click

How It Works

- Capture photos through the webcam.
- Photos are placed into predefined frame windows.
- Choose a frame background.
- Download a ready-made photostrip.

Tech Used

- HTML, CSS, JavaScript
- HTML5 Canvas for rendering and clipping
- getUserMedia() for webcam access
